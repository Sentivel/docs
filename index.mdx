Sentivel monitors your services, publishes a status page, and watches the providers you depend on, so an upstream outage shows up on your page in your own words. A status page with monitoring and no dependencies
is a complete setup.

A REST API and a hosted MCP server let CI pipelines, infrastructure as code, and AI agents manage monitors, status pages, incidents, and the rest of a workspace. Start with the [API overview](/api-overview), then browse the
[API reference](/me) for every endpoint.
